Markwrite's Github, Newsprint, Night and Whitey CSS is independently written
for its own reader and CodeMirror 6 editor. It follows the reference themes'
observable typography (font families, size relationships, spacing, colors,
heading rules, tables and block quotations), rather than redistributing their
unlicensed source files. The upstream repository has no root LICENSE at the
reference revision. These are adaptations, not identical Typora themes or an
endorsement by Typora. App controls and editing behavior remain Markwrite's.

Pixyll's typography adaptation derives from themes/pixyll.css at the same
revision. That file identifies the theme as MIT-licensed, forked from pixyll.com,
with copyright (c) 2015 John Otander. The original project's MIT license and
copyright notices are preserved at pixyll/LICENSE.txt, retrieved from:
https://github.com/johno/pixyll/blob/master/LICENSE.txt
The adaptation scopes its selectors to Markwrite document surfaces, replaces
Typora-only UI rules with Markwrite controls, maps source decorations to
CodeMirror 6, uses local font files and preserves user font/size overrides.
No remote CSS, tracking resources or font services are requested at runtime.

Bundled fonts (unmodified)
-------------------------
Open Sans: github/400.woff, 400i.woff, 700.woff, 700i.woff, from the reference
repository themes/github directory. Font metadata declares Apache License 2.0
and "Digitized data copyright (c) 2010-2011, Google Corporation."
The complete license is github/Apache-2.0.txt.

PT Serif: newsprint/PT_Serif-Web-*.ttf, from the reference repository.
Copyright (c) 2010 ParaType Ltd. Reserved Font Names "PT Sans", "PT Serif"
and "ParaType". SIL Open Font License 1.1 is in newsprint/OFL.txt.

Merriweather: pixyll/Merriweather-*.ttf, from the reference repository.
Copyright (c) 2010-2013 Sorkin Type Co, Reserved Font Name "Merriweather".
SIL Open Font License 1.1 is in pixyll/Merriweather-OFL.txt.

Lato: pixyll/Lato-*.ttf, from the reference repository.
Copyright (c) 2010-2011 tyPoland Lukasz Dziedzic, Reserved Font Name "Lato"
(as identified in the bundled font files). The full SIL Open Font License 1.1
and current project notice are in pixyll/Lato-OFL.txt, retrieved from:
https://github.com/google/fonts/blob/main/ofl/lato/OFL.txt

Vollkorn: whitey/Vollkorn.ttf and whitey/Vollkorn-Italic.ttf, unchanged copies
of Vollkorn[wght].ttf and Vollkorn-Italic[wght].ttf from:
https://github.com/google/fonts/tree/main/ofl/vollkorn
Copyright 2017 The Vollkorn Project Authors.
SIL Open Font License 1.1 is in whitey/OFL.txt.

CSS font family aliases (e.g. "Markwrite Vollkorn") select these local fonts;
they do not modify the font binaries. CJK characters fall back to installed
Noto/Source Han/SimSun fonts. Font licenses remain separate from app code.
