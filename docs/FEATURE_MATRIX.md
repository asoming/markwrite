# 功能实现与验收矩阵

对应原始 [PRD v0.1](PRD.md)，以及用户追加的菜单式编辑、Windows 兼容和继续实现增强功能的要求。更新日期：2026-09-11；当前版本：0.2.0 功能预览。原始 PRD 保留原文，本表记录实际落地范围。

“已实现”表示存在可执行的产品路径；验证列单独说明自动化、实际文件检查与尚未完成的环境验收。不能据此将 PRD v1.0 的发布条件全部勾选完成。

## 仍未完成的验收与未提供的能力

1. 真实 Fcitx5 / IBus / Windows 输入法、Wayland、多屏和缩放；2 小时连续写作与 100 次切换、内存趋势、冷启动 10 次及真实输入到绘制 P95。
2. Windows 目标桌面的手动安装和文件交互验收；自动化冒烟不能覆盖全部目标机器。
3. 使用可用配置完成 AI、真实图床与发布服务联调。通用接口实现不代表兼容任意商业服务。
4. 任意代码插件、插件市场、全库关系大屏、跨工作区同步、高级表格计算与任意 CSS 主题包未提供。P2 原文是候选列表，本轮以表中的具体范围实现，未扩写原始 PRD。
