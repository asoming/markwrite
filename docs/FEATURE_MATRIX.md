# 功能实现与验收矩阵

对应原始 PRD v0.1，以及用户新增的菜单式编辑、Windows 兼容要求。2026-09-11 更新。

“已实现”表示有真实代码路径和对应验证，不表示完成所有操作系统 / 输入法验收。P2 原文仅为候选，没有明确接口定义的服务不冒充完成。

## 尚未计为完成的事项

1. 原始 PRD 的真实输入法、缩放、冷启动、P95 绘制和2小时连续使用验收。组件性能基准不能替代这些检查。
2. P2 未定义的开放语法插件、云图床、发布服务、插件市场以及高级关联视图。实现这些需要具体行为、服务协议和凭据，不使用空按钮伪装。
3. 实际 AI 模型请求：需要用户提供可用服务，产品只在用户明确点击时发送选区。
