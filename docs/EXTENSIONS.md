# 声明式编辑扩展

在「工具 → 编辑扩展」导入 JSON，先检查预览，再安装。可以启用、停用、导出或移除；不修改已经保存的文档。启用内置“日常写作”包即可使用 `==高亮==` 与 `%%重点%%`，也可以先选中文字，再点扩展中的高亮按钮。

扩展同时支持文字片段和可配置的行内标记。没有脚本、正则表达式、渲染回调、外部资源或系统权限，不能执行代码、读取文件或发起网络请求。规则包不是任意第三方代码插件的加载器。

```json
{
  "version": 1,
  "name": "我的标记",
  "description": "突出重点，保留 Markdown 原文",
  "enabled": true,
  "snippets": [
    { "name": "复习卡片", "markdown": "## 关键概念\n\n{{selection}}\n\n- [ ] 再复习一次\n" }
  ],
  "inlineSyntax": [
    { "name": "高亮", "open": "==", "close": "==", "color": "#fff0a6" },
    { "name": "提示", "open": "{!", "close": "!}", "color": "#dae7ff" }
  ]
}
```

`snippets` 可以留空或省略；`inlineSyntax` 可以省略。文字片段的 `{{selection}}` 替换为当前选区。语法按钮同样包装当前选区。

每条语法包含名称、开始标记、结束标记和六位 HEX 背景色。内容按普通文字转义显示，内部 HTML 或脚本不会执行，内部 Markdown 不会再递归渲染。代码块与行内代码保留字面内容。编辑、源码、阅读和导出始终使用同一份 Markdown；停用后语法恢复为原始标记。

标记为 2–8 个受支持的标点字符：`! % + = : ; ? ^ { } [ ] ~ _ -`。标准保留标记（例如 `**`、`__`、`~~`、`[[`）不能被覆盖，已启用规则的开始标记不能相同或互为前缀。规则匹配不跨行，单次内容最多 4096 个字符。

限额：每包最多 20 条语法、50 个片段；最多安装 32 包，启用总计最多 64 条语法；单片段最多 50000 字符，单包最多 250000 字符，持久化总计最多 2000000 字符。导入文件额外限制为 250000 字节。超出限额、未知属性和非法颜色会被拒绝。

当前扩展范围是模板和声明式行内标记。不加载 JavaScript 插件、不更改文件读写权限，也不声称兼容任意 Markdown 方言。
