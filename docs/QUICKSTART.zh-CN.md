# 墨页上手指南

以下操作适用于桌面版。像普通文字处理软件一样输入，再用菜单排版；不需要先学习 Markdown。

## 1. 开始写作与保存

在「文件 → 新建文档」创建空白页，点击正文输入。已有文档用「文件 → 打开文档…」；管理一整个目录时选「打开文件夹…」。

按 **Ctrl+S** 或选「文件 → 保存」。首次保存需选择位置并命名为 `.md` 文件。已有路径的文档默认自动保存，仍请查看底部保存状态。另存一份用「另存为…」。操作错了，按 **Ctrl+Z** 撤销。

## 2. 设置文字格式

用鼠标选中文字，再选「格式 → 粗体」「斜体」或「删除线」。把光标放在某段，选「段落 → 一级标题」「二级标题」；改回普通文字选「正文」。项目清单可用「无序列表」「有序列表」「待办列表」。

## 3. 插入和修改表格

1. 将光标放在目标位置，选「插入 → 表格 / 编辑当前表格…」。
2. 直接填写格子，第一行是表头。用「+行」「+列」增加内容；先选中格子，再用减号删除对应行或列。每列可设置对齐，也可从 Excel 复制格子后粘贴。
3. 点「插入」。之后将光标放回表格，再开同一菜单，修改后点「更新表格」。

## 4. 图片、公式与流程图

- **图片：**选「插入 → 图片… → 选择本地图片…」，选择图片文件；也可把图片拖进正文。
- **公式：**选「插入 → 数学公式…」，在「常用公式」选择勾股定理、分数等模板，再点「插入」。勾选「插在文字行内」可让公式跟随文字；复杂公式可修改下方 LaTeX 内容。
- **流程图：**选「插入 → 流程图…」，在「流程步骤，每行一个」依次填写“开始”“检查”“完成”等中文步骤，再点「插入」。需要分支等结构时可勾选「使用 Mermaid 源码」。

## 5. 阅读、源码与恢复

「视图 → 阅读模式」用于阅读和复制；继续写作选「即时渲染编辑」。想看原始标记时选「Markdown 源码」，三种模式使用同一份正文。

找回之前内容：选「视图 → 版本历史」，点一个时间查看差异，再点「恢复到编辑器（可撤销）」。确认后按 Ctrl+S 保存；不满意可撤销。历史在保存修改后产生。

## 6. 导出给别人

在「文件」选择「导出 PDF…」或「导出 Word 文档…」，选择排版模板，再点「选择位置并导出」。导出使用当前内容，不必先覆盖原文；若提示图片缺失或公式错误，修正后重试。

「工具」中的 AI、图床和发布需要自行配置兼容服务，明确点击发送才会联网。
