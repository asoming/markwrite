# v0.1.0 验证记录

## v0.1.1 关闭窗口修复

用户报告点击窗口关闭按钮没有响应。定位到 Tauri 的 `onCloseRequested` 在回调放行后调用 `destroy()`，原先只授予 `allow-close`，缺少 `core:window:allow-destroy`。现仅为主窗口补充该权限。

新增 2 项回归测试，直接调用已安装的 Tauri JavaScript SDK，并模拟原生事件：检查关闭链路涉及的命令具备权限，以及 `preventDefault()` 仍能阻止销毁。修复前第一项测试失败，补充权限后前端共 14 项通过。原生窗口实际点击关闭仍需用户复核。

验证日期：2026-09-11。此版本为开发预览，不代表已通过 PRD 的 v1.0 验收。

## 界面验证

通过真实浏览器交互检查以下功能：中文文本输入、任务勾选、标签切换后撤销、源码 / 即时渲染 / 阅读切换、表格显示、KaTeX 公式、含中文标签与箭头的 Mermaid 图表、大纲、主题切换、命令面板筛选与专注布局。刷新后能够恢复先前草稿与设置。

这些检查使用浏览器中的生产前端，不等同于 Linux WebView 验收。原生程序启动检查仅能确认进程正常存活；没有自动操作原生文件对话框或真实输入法候选窗口。

## 尚需验收与后续开发

1. Fcitx5 / IBus 中文组合输入，Wayland、缩放、多屏及长期写作稳定性。
2. 原生打开、另存为、自动保存、关闭提示、外部文件冲突及权限恢复的完整交互验收；目前文件写入核心有单元测试。
3. 离线 HTML 导出的原生交互验收，尤其是公式字体、图片和复杂图表。
4. 大文档性能与内存基准。当前约 300KB 后暂停即时渲染，不能视为达到 PRD 性能要求。
5. 更完整的表格和行内公式编辑、首次保存时附件迁移、原生文件监控、可取消搜索。
6. 多版本历史、双链、PDF / DOCX、Git 界面、插件等扩展功能。
